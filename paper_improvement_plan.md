# Paper Improvement Plan: Proving “Cubical Foundations Have Coherence Depth Two and Therefore Scale by Fibonacci Recurrence”

## 0. Purpose of this plan

This document turns the current proof strategy into a concrete plan for the next version of the paper and the accompanying Agda artifact.

The goal is to upgrade the current paper from a theorem about a theorem-facing synthetic calculus to a stronger theorem about cubical foundations, while keeping the statement precise enough to be true and mechanizable.

The guiding slogan is:

> Cubical foundations have coherence depth two and therefore scale by Fibonacci recurrence.

The paper should **not** present this slogan in an unrestricted form. The mathematically defensible theorem is:

> In a cubical foundation with stable Kan composition/filling, the primitive public structural trace required to seal admissible foundational extensions has exact coherence depth two. Therefore, fully coupled sequences of sealed foundational extensions obey a depth-two affine recurrence; with constant payload, the shifted trace sequence is Fibonacci.

This plan gives:

1. the exact theorem hierarchy to prove;
2. the missing semantic bridge that must be added;
3. the paper edits needed to make the result reviewer-proof;
4. the Agda module architecture needed to support the theorem;
5. a staged implementation roadmap with acceptance criteria;
6. a risk register and mitigation strategy.

---

## 1. Core theorem to aim for

### 1.1 Informal theorem

Cubical foundations support higher-dimensional objects and higher paths at all dimensions. The theorem is not that higher coherences do not exist. The theorem is that, for **admissible sealed structural extensions**, higher structural obligations do not require new **primitive public trace** beyond binary trace.

Equivalently:

- unary trace records action on existing interface sites;
- binary trace records comparison/coherence between adjacent exported actions;
- higher horn-shaped structural material is canonically generated by cubical composition/filling and is therefore derived trace, not primitive public trace.

Thus the primitive trace depth is exactly two.

Once exact depth two is established, a fully coupled sealed extension at stage `n + 1` must integrate exactly the exported interfaces of stages `n` and `n - 1`. If the stage `n` exported interface has payload size `κ_n` and trace size `μ_n`, then:

```text
|I_n| = κ_n + μ_n
```

Full coupling gives:

```text
T_{n+1} ≃ I_n ⊔ I_{n-1}
```

Therefore:

```text
μ_{n+1} = μ_n + μ_{n-1} + κ_n + κ_{n-1}.
```

With constant payload `κ_n = c`, define:

```text
U_n = μ_n + 2c.
```

Then:

```text
U_{n+1} = U_n + U_{n-1}.
```

So the shifted trace sequence is Fibonacci.

### 1.2 Formal theorem schema

Introduce a record of cubical foundations:

```agda
record SemanticCubicalFoundation : Type₁ where
  field
    -- interval and endpoints
    I      : Type
    i0 i1  : I

    -- face/cofibration/partial machinery
    Cof        : Type
    Partial    : Cof → Type ℓ → Type ℓ
    _[_↦_]     : ...

    -- path, transport, composition, filling
    Path       : Type ℓ → Type ℓ

    hcomp      : ...
    hfill      : ...

    -- laws/stability under substitution
    hcomp-boundary-law : ...
    hfill-boundary-law : ...
    substitution-stability : ...

    -- optional, used for lower bounds
    univalence-structure : MaybeUnivalenceStructure
```

Then prove:

```agda
primitive-trace-depth-at-most-two :
  (F : SemanticCubicalFoundation) →
  (A : AdmissibilityPackage F) →
  PrimitiveTraceDepthAtMost F A 2
```

```agda
binary-trace-necessary :
  (F : SemanticCubicalFoundationWithUnivalence) →
  BinaryTraceNecessary F
```

```agda
cubical-foundations-primitive-coherence-depth-exactly-two :
  (F : SemanticCubicalFoundationWithUnivalence) →
  (A : AdmissibilityPackage F) →
  PrimitiveCoherenceDepthExactly F A 2
```

Then prove the scaling theorem:

```agda
full-coupling-depth-two-affine-recurrence :
  (S : SealedExtensionSequence F) →
  FullCoupling S →
  PrimitiveCoherenceDepthExactly F A 2 →
  (n : Nat) →
  μ S (n + 1) ≡ μ S n + μ S (n - 1) + κ S n + κ S (n - 1)
```

And the constant-payload Fibonacci corollary:

```agda
constant-payload-fibonacci-scaling :
  (S : SealedExtensionSequence F) →
  FullCoupling S →
  ConstantPayload S c →
  Bootstrap S →
  (n : Nat) →
  μ S n + 2 * c ≡ c * fib (n + 2)
```

The exact indexing can be adjusted to the existing `Core.AffineRecurrence` conventions. The key is that the paper and code must agree.

## 2. Important guardrails

These guardrails should be stated explicitly in the paper, preferably in the introduction, theorem statement, and limitations section.

### 2.1 Do not claim higher cubical objects disappear

Cubical foundations contain higher paths, cubes, homotopies, HIT constructors, and higher-dimensional structures. The theorem concerns the **primitive public trace needed to seal structural extensions**, not the existence of higher-dimensional objects.

Recommended wording:

> Higher cubical cells may exist at every dimension. Our theorem says that higher structural integration obligations are not additional primitive public trace; they are derived from binary trace by the cubical Kan structure.

### 2.2 Do not count arbitrary user HIT constructors as structural trace

A user can introduce a primitive higher-dimensional constructor in a HIT. That constructor should be classified as payload, not as automatically generated structural integration trace.

Recommended wording:

> User-supplied higher constructors are payload. The depth theorem applies to structural integration trace generated by sealing a foundational extension, not to arbitrary semantic payload supplied by the user.

### 2.3 Do not count transparent definitions as sealed layers

Transparent definitional growth elaborates inside the existing library state. It has zero integration latency in the intended model. Only opaque/sealed extension boundaries contribute to the recurrence.

Recommended wording:

> The recurrence is not a law of ordinary transparent library growth. It is a law of sealed extension sequences in which the resolved public trace is exported as part of the interface.

### 2.4 Do not claim all sequences are Fibonacci

Fibonacci growth requires **full coupling**. Sparse or orthogonal extensions satisfy a sub-recurrence or upper-bound envelope, not equality.

Recommended wording:

> Full coupling is a maximal regime. Sparse dependency footprints yield sparse recurrences bounded by the full-coupling envelope.

### 2.5 Avoid contractibility overreach

The proof should not assert that all semantic higher filler spaces are contractible. In homotopy type theory, higher path/filler spaces can be nontrivial. The theorem should assert that the **primitive public trace normal form** for higher structural material is derived.

Recommended wording:

> We do not require the space of all fillers to be contractible. We require that the additional exported trace field is canonically computable from the depth-two boundary using cubical filling/composition, hence is not primitive trace.

## 3. The theorem hierarchy

The final paper should not present the result as one monolithic theorem. It should present a sequence of lemmas that reviewers can inspect independently.

### 3.1 Theorem A: Semantic sealed extension calculus

**Claim.** A sealed foundational extension decomposes into payload and resolved structural trace:

```text
I_n = K_n ⊔ T_n.
```

Payload is user/foundation content. Trace is the public integration data required by downstream sealed extensions.

**Purpose.** Establishes what is being counted.

**Code location.** New module:

```text
agda/Semantics/SealedExtension.agda
```

**Paper location.** Section 2 or 3, before the depth theorem.

### 3.2 Theorem B: Raw extension adequacy

**Claim.** Every admissible sealed structural extension in the semantic cubical foundation elaborates into the raw extension calculus, and the elaboration preserves:

1. semantic interpretation;
2. historical support;
3. primitive-vs-derived trace classification;
4. exported interface cardinality.

This is the critical bridge from the current synthetic calculus to the full theorem.

**Subclaims.**

```text
raw-syntax-sound-for-semantic-extensions
semantic-structural-extension-elaborates-to-raw
raw-normalization-preserves-semantics
raw-normalization-preserves-support
raw-normalization-preserves-primitive-cost
raw-normalization-preserves-cardinality
```

**Code location.** New module:

```text
agda/Semantics/RawAdequacy.agda
```

**Paper location.** New section: “Semantic adequacy of the extension calculus.”

### 3.3 Theorem C: Normal form theorem

**Claim.** Every admissible structural trace field normalizes to exactly one of:

1. unary action trace;
2. binary comparison trace;
3. derived horn package.

Unary and binary trace fields may be primitive. Higher horn packages are derived.

**Code location.** Existing modules to strengthen:


New semantic wrapper:


**Paper location.** Section before the upper-bound proof.

### 3.4 Theorem D: Semantic horn reduction

**Claim.** Every higher structural obligation with historical support beyond two factors through:

```text
binary boundary + derived cubical horn chain.
```

This theorem must be semantic, not merely syntactic. It should use the cubical foundation’s `hcomp`/`hfill` operations.

**Important refinement.** The theorem should state that the higher structural obligation is **derived trace**, not that every semantic filler space is contractible.

Possible theorem names:

```text
semantic-horn-extension-derived
higher-structural-obligation-derived-by-hfill

```

**Code location.** New module:

```text

```

**Paper location.** Main upper-bound proof section.

### 3.5 Theorem E: Upper bound, depth at most two

**Claim.** For every admissible sealed structural extension and every historical support depth `k ≥ 2`, primitive trace at depth `k` is equivalent to primitive trace at depth two.

```text
PrimTrace(k) ≃ PrimTrace(2)
```

**Code location.** New module:

```text

```

This module should import the semantic adequacy theorem and semantic horn reduction theorem.


**Code location.** New module:

### 3.7 Theorem G: Exact primitive coherence depth two

**Claim.** Combining upper and lower bounds:

```text
PrimitiveCoherenceDepthExactly F 2
```

Possible theorem names:

```text

```

**Code location.** New module:

```text

```

### 3.8 Theorem H: Chronological window theorem

**Claim.** Exact primitive depth two implies the primitive trace required at stage `n + 1` depends only on the exported interfaces of stages `n` and `n - 1`.

```text
PrimTrace_{n+1} ⊆ I_n ⊔ I_{n-1}
```

For full coupling:

```text
PrimTrace_{n+1} ≃ I_n ⊔ I_{n-1}
```

**Code location.** New or updated modules:

```text
agda/Semantics/ChronologicalWindow.agda
agda/Semantics/FullCoupling.agda
```

The current `Metatheory.UniversalRecurrence` and `Metatheory.SparseDependencyRecurrence` should be refactored to consume this semantic theorem.

### 3.9 Theorem I: Affine recurrence

**Claim.** If `I_n = K_n ⊔ T_n`, `|K_n| = κ_n`, `|T_n| = μ_n`, and full coupling holds, then:

```text
μ_{n+1} = μ_n + μ_{n-1} + κ_n + κ_{n-1}.
```

**Code location.** Update:

```text
agda/Metatheory/UniversalRecurrence.agda
agda/Metatheory/FullCouplingEnvelope.agda
```

Optional new semantic-facing wrapper:

```text
agda/Semantics/ScalingRecurrence.agda
```

### 3.10 Theorem J: Constant-payload Fibonacci corollary

**Claim.** If `κ_n = c`, then the shifted sequence `U_n = μ_n + 2c` satisfies the Fibonacci recurrence.

Depending on indexing:

```text
U_n = c * fib (n + 2)
μ_n = c * fib (n + 2) - 2c
```

or the corresponding existing `Delta-bootstrap` indexing.

**Code location.** Existing arithmetic is mostly in:

```text

```

Add a semantic-facing theorem:

```text
agda/Semantics/FibonacciScaling.agda
```

## 4. Paper update plan

### 4.1 Title and abstract

The current title can remain if it is already centered on coherence depth, but the abstract should become more precise.

Recommended abstract framing:

> We prove that the primitive public structural trace of admissible sealed extensions in cubical foundations has exact coherence depth two. Higher cubical objects and higher paths are not eliminated; rather, higher structural integration obligations are shown to be derived from binary trace by the Kan composition/filling structure. Under full coupling, the two-layer chronological window induces an affine depth-two recurrence for trace growth, whose constant-payload specialization is Fibonacci.

Avoid saying:

> Higher coherences vanish.

Prefer:

> Higher structural trace is derived.

### 4.2 Introduction

Add a paragraph distinguishing four notions:

1. higher cubical objects;
2. higher structural obligations;
3. primitive public trace;
4. derived trace.

Suggested language:

> The theorem is not a truncation theorem. Cubical foundations still support higher-dimensional cubes and higher paths. The depth-two result is a statement about the minimal primitive public trace needed at sealed extension boundaries. Higher structural obligations are realized, but their public trace is generated by cubical horn filling from binary boundary data.

Add a “scope at a glance” table:

| Included | Excluded |
|---|---|
| Sealed foundational extension boundaries | Transparent definitions |
| Structural integration trace | Arbitrary user payload |
| Full-coupling recurrence equality | Sparse/orthogonal growth equality |
| Higher obligations as derived trace | Claim that higher objects vanish |

### 4.3 Preliminaries

Add or strengthen definitions for:

- sealed extension;
- public interface;
- payload;
- resolved trace;
- primitive trace;
- derived trace;
- historical support;
- coherence depth;
- chronological window;
- full coupling.

The paper should introduce the semantic concepts before the raw calculus. The raw calculus should then be presented as an adequate normal-form calculus for these semantic objects.

### 4.4 New section: Semantic cubical foundations

Introduce a record-like definition in prose.

A cubical foundation should provide:

1. interval object and endpoints;
2. cofibrations/faces;
3. partial elements;
4. path types or interval-indexed equality;
5. transport;
6. homogeneous composition;
7. filling;
8. substitution stability;
9. optionally univalence for the lower-bound witness.

State that the theorem is parametric in this structure.

Define a sealed extension:

```text

```

with public interface:

```text
I_n = K_n ⊔ T_n.
```

Define transparent development separately and state it is outside the recurrence.

Add a lemma:

```text

```

This can be connected to the existing formal `TransparentDevelopment` material.

### 4.6 New section: Adequacy of the raw extension calculus

This is the largest conceptual addition.

Current paper likely moves too quickly from raw syntax to theorem-facing results. The next version should make the bridge explicit.

Structure this section as:

1. Define semantic structural obligations.
2. Define raw clauses: action, comparison, horn.
3. Prove soundness: raw well-typed clauses interpret as valid semantic structural obligations.
4. Prove completeness: every admissible semantic structural obligation is represented by a raw clause.
5. Prove preservation: support, primitive/derived status, and cardinality are preserved.

If full mechanization is not yet complete, present the adequacy theorem as a named assumption or theorem with a clear status label:

```text
Theorem 3.x (Semantic adequacy, mechanized except completeness sublemma Y).
```

But the best target is to mechanize at least a record of adequacy assumptions and make all downstream theorems parametric in that record. This avoids pretending the bridge is done while still allowing the rest of the theorem to be formally checked.

### 4.7 New section: Normal forms for structural trace

State and prove:

```text
Every admissible structural trace field normalizes to unary action, binary comparison, or derived horn package.
```

Explain:

- unary action = primitive candidate;
- binary comparison = primitive candidate;
- horn package = derived by cubical Kan structure.

This section should explicitly explain why higher algebraic operations are payload, not structural trace.

### 4.8 Main proof section: Depth at most two

Recommended proof skeleton:

1. Let `o` be a structural obligation with support depth `k ≥ 2`.
2. Normalize `o` to a canonical trace normal form.
3. If `o` is unary or binary, it is already supported within depth two.
4. If `o` is higher, it is a horn package.
5. By cubical `hfill`/`hcomp`, the higher horn trace is derived from its boundary.
6. Its boundary factors through the most recent two exported layers by telescopic subsumption.
7. Therefore no primitive trace beyond depth two remains.

The proof should avoid saying “higher fillers are unique.” It should say “the exported higher structural trace is computationally generated, hence non-primitive.”

### 4.9 Main proof section: Depth at least two

Use the swap or clutching witness.

Recommended proof with swap:

1. Let `Two` be the two-point type.
2. Let `swap : Two ≃ Two` be the nontrivial equivalence.
3. By univalence, obtain a path `p : Two ≡ Two`.
4. Transporting a unary clause along `p` sends constant-left to constant-right.
5. Constant-left and constant-right are distinguishable.
6. Therefore the binary comparison between `refl` and `p` cannot be derived from unary trace alone.
7. Hence primitive coherence depth is not one.

Then optionally add the clutching witness as a geometrically richer example.

### 4.10 Exact depth theorem

Combine:

```text
depth ≤ 2
```

and:

```text
depth > 1
```

to conclude:

```text
depth = 2.
```

Recommended theorem statement:

> The primitive public structural coherence depth of admissible sealed extensions in a cubical foundation with univalence is exactly two.

### 4.11 Scaling theorem section

Separate the depth theorem from the scaling theorem.

Definitions:

```text
K_n = payload of layer n
T_n = trace of layer n
I_n = K_n ⊔ T_n
κ_n = |K_n|
μ_n = |T_n|
```

Chronological window theorem:

```text
T_{n+1} ⊆ I_n ⊔ I_{n-1}
```

Full coupling assumption:

```text
T_{n+1} ≃ I_n ⊔ I_{n-1}
```

Counting:

```text
μ_{n+1}
= |T_{n+1}|
= |I_n ⊔ I_{n-1}|
= |I_n| + |I_{n-1}|
= (κ_n + μ_n) + (κ_{n-1} + μ_{n-1}).
```

Then constant payload:

```text
μ_{n+1} = μ_n + μ_{n-1} + 2c.
```

Shift:

```text
U_n = μ_n + 2c.
```

Then:

```text
U_{n+1} = U_n + U_{n-1}.
```

## 9. Reviewer-facing narrative

The next version should tell the story this way:

1. Cubical type theory has higher-dimensional structure.
2. The question is not whether higher cells exist, but how much primitive public trace must be exported when sealing foundational extensions.
3. Sealed extensions split into payload and trace.
4. Structural trace normalizes into unary action, binary comparison, and higher horn packages.
5. Higher horn packages are derived from cubical Kan composition/filling.
6. Binary trace is necessary, witnessed by swap/clutching.
7. Therefore primitive structural trace has exact depth two.
8. A two-layer chronological window follows.
9. Under full coupling, the next trace is exactly the public interface of the previous two layers.
10. Counting yields the affine recurrence.
11. Constant payload yields Fibonacci scaling.

This narrative is stronger and safer than saying “cubical foundations are depth two” without qualification.

## 10. Risk register

### Risk 1: Semantic adequacy is too hard

**Problem.** The completeness direction may be difficult: every semantic structural obligation must elaborate to the raw calculus.

**Mitigation.** Make downstream theorems parametric in `RawAdequacyPackage`. Then instantiate the package for the fixed extension calculus as much as possible. In the paper, clearly distinguish the conditional metatheorem from the instantiated theorem.

### Risk 2: The theorem accidentally counts arbitrary HIT constructors

**Problem.** A user-defined higher constructor can be primitive at any dimension.

**Mitigation.** Classify user-supplied higher constructors as payload, not structural trace. Add a case study showing this classification.

### Risk 3: The horn theorem overclaims contractibility

**Problem.** Higher filler spaces can be nontrivial.

**Mitigation.** State derived-trace computability, not semantic filler-space contractibility.

### Risk 4: Full coupling is mistaken for a universal law

**Problem.** Reviewers may object that real libraries are sparse.

**Mitigation.** Present full coupling as the maximal regime. Include sparse recurrence theorem and examples.

### Risk 5: Indexing mismatch in Fibonacci formula

**Problem.** Paper and Agda arithmetic may use different base indices.

**Mitigation.** Add an indexing convention box and a smoke theorem that prints the first few values.

### Risk 6: Universe levels become unmanageable

**Problem.** Abstract semantic records can produce painful universe constraints.

**Mitigation.** Split `SemanticCubicalFoundation` into smaller records and keep theorem-facing modules universe-polymorphic only where necessary.

### Risk 7: The artifact looks like it assumes the theorem

**Problem.** If horn trace is simply classified as derived by definition, reviewers may say the result is built in.

**Mitigation.** Add a semantic derivation theorem using `hfill`/`hcomp`, and make the raw classifier sound with respect to that derivation.

## 13. Recommended final theorem statement for the paper

Use a theorem statement close to this:

> **Theorem.** Let `F` be a cubical foundation with substitution-stable Kan composition and filling, and let `A` be an adequacy package interpreting admissible sealed structural extensions of `F` in the canonical raw extension calculus. Then the primitive public structural trace of `F` has exact coherence depth two: every primitive trace field of support depth greater than two is equivalent, up to canonical derived horn trace, to a field supported on the most recent two layers, and there exists a binary structural obligation not derivable from unary trace alone.

Then state the scaling theorem separately:

> **Theorem.** Let `(E_n)` be a fully coupled sequence of sealed foundational extensions in such a foundation. If `κ_n` is the payload size and `μ_n` is the primitive trace size of layer `n`, then
>
> ```text
> μ_{n+1} = μ_n + μ_{n-1} + κ_n + κ_{n-1}.
> ```
>
> If `κ_n = c` is constant and the bootstrap convention is `μ_1 = 0`, `μ_2 = c`, then the shifted sequence `U_n = μ_n + 2c` is Fibonacci, equivalently `U_n = c F_{n+2}`.

This keeps the slogan while making the mathematical content precise.
