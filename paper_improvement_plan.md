# Paper Improvement Plan: Making *Coherence Depth and Affine Recurrence in a Cubical Extension Calculus* Publishable as a Theorem Paper

## Executive diagnosis

The paper has a promising thesis: once one fixes a sealed, fully coupled extension calculus, separates exact obligation depth from minimal public-signature depth, and counts only normalized irreducible public trace schemas, a depth-two chronological window yields an affine recurrence, with a Fibonacci specialization under constant payload size.

The current draft is not yet fully convincing as a theorem paper because too many load-bearing notions are introduced informally and then used as if they were already formalized. The recurrence theorem is algebraically clear once the model assumptions are granted; the weak points are the foundations underneath that model:

1. the formal theorem object is not specified as inference rules or algebraic data;
2. `O^(k)(X)` is used both as a finite set/signature of obligation schemas and as a dependent type with contractible fibers;
3. the crucial horn-extension contractibility claim is underproved;
4. “fully coupled,” “global admissibility,” and “basis coverage” risk being partly definitional;
5. basis uniqueness is asserted from finite minimality, which is not valid without additional structure;
6. the lower-bound example should be reformulated so it is a precise promoted-interface obstruction, not a dubious global polymorphic endomap;
7. the Agda mechanization is described in detail but not supplied as a reproducible artifact.

The path to an eminently publishable version is therefore not to add more rhetoric, but to make the paper look like a small, exact metatheorem about a deliberately specified calculus. The final version should say, in effect:

> We define a sealed, fully coupled cubical extension calculus. In that calculus, under explicitly stated normalization, opacity, support, and horn-generation rules, higher structural-integration obligations factor through contractible cubical horn-extension packages, binary obligations are genuinely necessary, and the presentation-invariant opaque trace cost obeys a depth-two affine recurrence.

That statement is interesting, defensible, and reviewable.

## Target revised main theorem

The paper should converge toward one prominent theorem package, stated early and then proved modularly.

### Proposed main theorem statement

Let `E_CCHM` be the sealed fully coupled extension calculus over the chosen CCHM-style cubical core, with:

- raw declarations, sealing, opacity, and normalized public signatures defined by explicit rules;
- presentation equivalence generated by a finite list of normalizing moves;
- canonical primitive/derived tagging of public trace fields;
- historical support and arity computed on normalized signatures;
- a fully coupled active footprint equal to the current chronological window;
- a proved raw-to-canonical bridge from admissible declarations to normalized trace signatures;
- a proved cubical horn-generation theorem for structural-integration obligations.

Then:

1. **Exact upper bound:** for every foundational candidate `X` and every `k >= 2`, the exact normalized obligation object at depth `k` is equivalent to the depth-two object, possibly after projecting away a canonical contractible horn factor.
2. **Minimal-signature upper bound:** every admissible declaration is presentation-equivalent to one whose normalized public trace signature contains no irreducible primitive historical trace field of arity greater than two.
3. **Chronological window:** every surviving primitive binary trace field factors through the previous two normalized signatures.
4. **Lower bound:** there exists a promoted-interface candidate over a univalent active interface for which unary data do not determine sealing; a binary obligation is genuinely required.
5. **Depth conclusion:** the obligation depth of `E_CCHM` is exactly two, and the minimal-signature depth is at most two.
6. **Cost recurrence:** if `mu_n` is the minimal opaque trace cost of layer `n` and `kappa_n` is the core payload size of layer `n`, then any foundation whose exact depth-two result is realized by a chronological window of size two satisfies

   ```text
   mu_{n+1} = mu_n + mu_{n-1} + kappa_n + kappa_{n-1}.
   ```

   Under constant payload size `kappa_n = c`, this becomes

   ```text
   mu_{n+1} = mu_n + mu_{n-1} + 2c,
   ```

   and the shifted sequence `U_n = mu_n + 2c` satisfies the Fibonacci recurrence.

### Important wording change

Avoid claiming “cubical coherence has Fibonacci growth.” The theorem is about **minimal opaque trace cost in the fixed sealed fully coupled extension calculus**. The stronger phrase invites reviewers to object that ordinary cubical libraries, sparse modules, transparent definitions, and user-level developments do not behave this way.

Recommended abstract wording:

> In the sealed, fully coupled extension calculus defined here, the depth-two chronological window forces a payload-aware affine recurrence for minimal opaque trace cost. This is a worst-case foundational-core theorem, not a model of arbitrary library growth.

### Priority 2: Separate signatures, index sets, and realized types

This is the single most important mathematical cleanup.

Currently `O^(k)(X)` is introduced as “the set of normalized atomic obligation types,” but later the paper treats it as a dependent type that can be written as a dependent sum over `O^(k-1)(X)` with contractible fibers. Those are not the same object.

Replace the current notation with a three-level distinction.

#### Suggested notation

```text
ObSig_k(X)      finite normalized obligation signature at depth k
Ix_k(X)         finite set of primitive schema indices in ObSig_k(X)
Real_k(X)       dependent type/space interpreting the obligation signature
Prim_k(X)       primitive irreducible part of ObSig_k(X)
Der_k(X)        derived/transparent part of ObSig_k(X)
```

Then state theorems at the right level:

```text
Exact stabilization:
  Real_k(X) ~= Real_2(X)    for k >= 2

Minimal-signature elimination:
  Prim_k(X) has no fields of historical arity >= 3 in mu-minimal normal form

Counting theorem:
  mu(e) = |PrimTrace(N(e))|

Contractible-factor theorem:
  Real_k(X) ~= Real_2(X) x C_k(X), with C_k(X) contractible
```

This will also fix the tension in the current text between “higher exact obligation types remain present” and “`O^(k)(X) ≃ O^(2)(X)`.” Under the revised notation, higher horn factors can remain present in `ObSig_k(X)` while contributing a contractible factor to `Real_k(X)` and no primitive field to `PrimTrace`.

**Acceptance criterion:** every theorem should say whether it concerns a syntax/signature object, a finite primitive index set, a realized type/space, or a cardinality.

### Priority 3: Repair the horn-extension contractibility argument

The paper’s hardest mathematical step is the move from cubical Kan operations to “the horn-extension fiber is canonically contractible.” This must be proved, not asserted.

A skeptical reviewer will object:

> Kan filling provides a filler operation. It does not automatically prove that the type of all fillers of a horn is contractible.

The revised paper must take one of two routes.

#### Route A: Prove actual contractibility

Define the exact horn-extension object so precisely that a center and contraction can be constructed.

For each boundary `partial`, define:

```text
H_k(partial) := Sigma (gamma : Gamma_miss(partial)). Fill_partial(gamma)
```

Then provide:

```text
center(partial) : H_k(partial)
center(partial) = (hcomp partial, hfill partial)

contract(partial) : (z : H_k(partial)) -> Path_{H_k(partial)} center(partial) z
```

The proof must explain why `contract` exists. Merely defining `center` is insufficient.

If the contraction uses definitional equality, the paper must specify the normalization quotient that identifies arbitrary presented horn witnesses with the canonical `hcomp/hfill` witness. If it uses path equality inside cubical type theory, the exact path construction must be shown or referenced in the Agda artifact.

#### Route B: Weaken the exact theorem and keep the cost theorem

If actual contractibility of the horn solution type is not available, revise the main theorem:

- keep the statement that `hcomp/hfill` gives a canonical derived witness;
- prove elimination from `mu`-minimal public signatures;
- prove the chronological-window recurrence from primitive support, not from exact obligation-type equivalence;
- remove or weaken the statement `O^(k)(X) ≃ O^(2)(X)`.

The paper can still be valuable under Route B. The recurrence only needs a window theorem for primitive public trace support. It does not require a strong theorem about the homotopy type of all horn fillers.

**Acceptance criterion:** the revised Theorem 4.13 is either a fully formal contraction theorem with center and contraction, or it is downgraded to the exact statement actually proved by the canonical-replacement calculus.

### Priority 4: Fix basis uniqueness

Theorem 2.17 currently argues that finite minimal generating families have canonical bijections. That is not true in general. Minimal generating sets can have different cardinalities unless the generation relation has special exchange or normal-form properties.

The paper should replace the generic minimal-generating-family argument with a normalization theorem.

#### Recommended replacement

Define a canonical primitive class set directly:

```text
PrimClasses(S(L)) := irreducible normal-form fields of the normalized public signature of L,
                    modulo transparent-generation equivalence.
```

Then define:

```text
S_bas(L) := PrimClasses(S(L)).
```

Now “basis uniqueness” is no longer a theorem about arbitrary finite minimal generating sets. It is a theorem about uniqueness of normal forms:

```text
Theorem: If N(L) and N'(L) are presentation-equivalent normalized public signatures, then
PrimClasses(N(L)) ~= PrimClasses(N'(L)).
```

If the author wants to keep the language of “basis families,” define a basis family as a chosen transversal of `PrimClasses`, and prove that all transversals are canonically bijective by projection to the class set.

**Acceptance criterion:** no theorem relies on the false principle that arbitrary finite minimal generating families are canonically bijective.

### Priority 5: Clarify the per-site versus per-payload counting convention

Definition 2.13 says each atomic payload generator must have behavior specified against every active basis site. Theorem 2.22 then states that the integration latency is exactly the number of active basis sites. These are compatible only if a single trace schema per active basis site packages the behavior of the entire new payload package.

The paper must explicitly choose one of these conventions.

#### Convention A: One trace schema per active basis site per layer

A layer’s payload, no matter how many internal payload generators it contains, is treated as one global action package. For each active basis site, the public trace field is a dependent record containing all behavior of the whole package at that site.

Then Theorem 2.22 can remain:

```text
Delta(X | B_n) = |I_{n,bas}^{(k)}|.
```

But the paper must state:

```text
A trace schema is counted after bundling all payload-generator actions at one active basis site into one irreducible package-field.
```

#### Convention B: One trace schema per payload generator per active basis site

Then the density theorem should be:

```text
Delta(X | B_n) = kappa(X) * |I_{n,bas}^{(k)}|,
```

or more generally a matrix/footprint count. The recurrence would change.

The current recurrence depends on Convention A. That convention is defensible, but it must be made explicit.

**Acceptance criterion:** a reviewer should not be able to ask, “Why is there no factor of `kappa_{n+1}` in the sealing cost?”

---

### Priority 6: Recast “fully coupled” as a formal hypothesis, not a disguised conclusion

The current text says that fully coupled foundations are globally acting and then proves coverage/density. This risks seeming circular: global action means it acts on all sites, so coverage follows.

Make the logical status explicit:

```text
Definition: FullFootprint(B_n, d) is the selected active basis footprint.
Rule: A declaration e is fully coupled at depth d only if its action telescope has one primitive action/comparison slot for each site in FullFootprint(B_n, d), modulo canonical derivability.
Theorem: After normalization, a fully coupled admissible declaration contributes exactly one irreducible primitive trace schema per footprint site.
```

Alternatively, if coverage is intended to follow semantically from canonicity, state a semantic adequacy assumption:

```text
Assumption: Any omitted primitive active basis site yields a stuck operational case or an incomplete exported total action.
```

Then prove coverage from that assumption. Do not make the proof sound like a universal theorem about all cubical extensions.

**Acceptance criterion:** the paper clearly distinguishes modeling assumptions, admissibility rules, and derived consequences.

### Section 4: Obligation depth and cubical dichotomy

This section needs the most mathematical tightening.

#### Replace Definition 4.1

Current definition:

```text
O^(k)(X) = set of normalized atomic obligation types
```

Revised definition:

```text
ObSig_k(X) : normalized obligation signature
Real_k(X)  : realized type of full depth-k obligation packages
Ix_k(X)    : finite index set of normalized atomic obligation schemas
PrimIx_k(X): primitive irreducible schema indices
```

Then define inclusions at the signature/index level and equivalences at the realization level.

#### Strengthen the taxonomy in Remark 4.2

Turn the taxonomy into a formal table used throughout the paper:

| Status | Formal object | Counted by `mu`? | Present in exact `Real_k`? |
|---|---|---:|---:|
| Primitive field | `PrimitiveTag(phi)` | yes | yes |

This will help reviewers see that “contractible,” “derived,” “eliminated,” and “absent” are not being conflated.

#### Repair Lemma 4.5

The arity-to-dimension correspondence is currently intuitive. For a theorem paper, make it either:

1. a definition of how the calculus assigns dimension to support arity; or
2. a lemma proved by induction on the obligation grammar.

A good revision:

```text
Definition: The obligation grammar has constructors Unary, Binary, and HornExtend_k.
The dimension function dim(o) is defined by this grammar.
Lemma: If support(o) has cardinality k and o is irreducible structural-integration coherence,
then dim(o) = k.
Proof: induction on the obligation grammar.
```

Do not present a broad philosophical claim about all higher-dimensional identity structure as if it were a formal theorem.

#### Rewrite Lemma 4.9 as the key upper-bound theorem

The current Lemma 4.9 says every `k >= 3` marginal obligation is a horn-extension fiber. This is the true heart of the paper and should be expanded.

Add:

- a diagram for `k = 3` with all faces labeled;
- a general inductive definition of the remote layer `L_{n-k+1}`;
- a statement of which faces are visible from prior public traces;
- a statement of which face is missing;
- the construction of `Gamma_miss^(k)(partial)`;
- the definition of `Fill_partial(gamma)`;
- a proof by induction using factorization-complete trace export.

The proof should not rely only on prose such as “by construction.”

#### Fix Theorem 4.13

Use one of the two routes described above:

- prove actual contractibility of `H_k(partial)` with a center and contraction; or
- weaken the theorem to the exact syntactic/cost statement actually implied by canonical replacement.

If actual contractibility is retained, the theorem should be stated as:

```text
Real_k(X) ~= Sigma (partial : Real_{k-1}(X)). H_k(partial)
forall partial, isContr(H_k(partial))
therefore Real_k(X) ~= Real_{k-1}(X)
therefore Real_k(X) ~= Real_2(X)
```

If the horn-extension fiber is contractible only after quotienting by canonical derived equality, call the object `Real_k^can(X)` or `CanonReal_k(X)`. Do not let readers think this is a theorem about the raw type of all cubical fillers.

#### Clarify Theorem 4.11

Theorem 4.11 should depend on Theorem 3.5 plus the horn-derived-tag theorem, not directly on contractibility unless contractibility is genuinely needed.

Recommended structure:

```text
Lemma: every arity >= 3 structural trace field receives a DerivedTag in the canonical trace presentation.
Theorem: derived-tagged fields are removed from mu-minimal signatures.
Corollary: d_mu <= 2.
```

This makes minimal-signature elimination cleaner and less dependent on the controversial exact contractibility step.

#### Rewrite Theorem 4.15

The recent-history factorization proof should become a formal induction on remote distance `r`.

Define a relation:

```text
FactorsThroughLastTwo(phi, L_n, L_{n-1})
```

Then prove:

```text
Base r = 2: assemble the open 3-box from public traces of L_n and L_{n-1}.
Step r -> r+1: use factorization-complete export of L_{n-r+1} and the induction hypothesis.
```

The theorem should explicitly say whether the resulting remote comparison is:

- definitionally equal;
- propositionally equal/path equal;
- equal in the normalized presentation quotient;
- merely presentation-equivalent.

The current phrase “definitionally equal” is strong. If the Agda development proves only normalized equivalence, say that.

### Section 4 lower bound: repair the swap example

The lower-bound theorem is promising but should be reformulated.

#### Current risk

The paper introduces a “global endomap package”

```text
f : Pi A : U. A -> A
```

and then chooses a unary clause on `2`:

```text
f_2 := lambda _. left
```

This is conceptually confusing. A true global polymorphic function is not the same as a partially specified action clause on an active interface. The lower-bound example should concern a **promoted interface candidate with objectwise unary clauses**, not an already-typed global term.

#### Recommended revised example

Define an active interface containing:

```text
Bool : U
left, right : Bool
swap : Bool ~= Bool
p_swap := ua(swap) : Bool =_U Bool
```

Define a promoted action candidate with a unary field for each active object:

```text
act_Bool : Bool -> Bool
```

Depth-one sealing checks only the objectwise unary clause. Choose:

```text
act_Bool = const left
```

Depth-two sealing must also check naturality/coherence along the exported universe path `p_swap`:

```text
transport_{A |-> A -> A}(p_swap, act_Bool) = act_Bool
```

By univalence, transport acts by conjugation with `swap`, so `const left` is transported to `const right`. The required equality would imply `right = left`, contradiction.

Then state the lower bound as:

```text
There exists a depth-one-valid unary promoted-interface candidate whose depth-two binary
coherence type is uninhabited. Therefore unary obligations do not determine sealing; depth
1 is insufficient.
```

This avoids pretending that the failed object is an admissible global endomap.

#### Add a positive control

Show that the identity action passes the same binary obligation:

```text
act_Bool = id
transport(p_swap, id) = id
```

This helps readers see that the example is not merely an inconsistent candidate, but a genuine distinction between unary and binary sealing.

#### Acceptance criterion

The lower-bound theorem should clearly distinguish:

- a unary candidate;
- a binary sealing obligation;
- admissibility after full sealing;
- failure of depth-one sufficiency.

### Section 5: Recurrence theorem

The recurrence is the cleanest part of the paper. It should be protected by making its hypotheses exact.

#### Rewrite Theorem 5.1

State it independently of cubical type theory:

```text
Theorem. Let E be a sealed extension calculus with:
  1. normalized basis cardinalities;
  2. payload/trace decomposition |S_bas(L_i)| = kappa_i + mu_i;
  3. a chronological window of size d for primitive support;
  4. full coupling to every basis site in that window.
Then
  mu_{n+1} = sum_{j=0}^{d-1} (mu_{n-j} + kappa_{n-j}).
```

Then state:

```text
Corollary. In E_CCHM, Theorems 4.13/4.15/4.20 supply d = 2.
```

This makes clear that the recurrence comes from the window theorem plus the trace principle, not from cubical geometry alone.

#### Add sparse recurrence before full recurrence or in an appendix

Since the introduction repeatedly excludes orthogonal extensions, add a compact sparse version:

```text
mu_{n+1} = sum_{i in Footprint(n+1)} (mu_i + kappa_i)
```

Then the fully coupled recurrence is the special case where `Footprint(n+1)` is the last `d` layers.

This will disarm the likely reviewer objection that real libraries are sparse.

#### Check indexing carefully

The paper uses `L_{n+1}` for the layer added by `B_n -> B_{n+1}`, but later lets `e_n` export `L_n`. Keep one convention throughout.

Add a small table:

| Symbol | Meaning |
|---|---|
| `B_n` | state after `n` sealed layers |
| `L_n` | nth sealed layer, added by `B_{n-1} -> B_n` |
| `e_n` | declaration sealing to `L_n` |
| `mu_n` | minimal trace cost of `L_n` |
| `kappa_n` | core payload size of `L_n` |

Then specify bootstrap:

```text
For n < d, nonexistent layers contribute empty signatures.
```

## Definitions to add or tighten

### 1. Normalized public signature

Define it as a finite telescope with fields tagged as payload/trace and primitive/derived:

```text
N(e) = (fields, dependency_order, tag_payload_trace, tag_primitive_derived, support)
```

The normal form should be unique up to canonical renaming and telescope isomorphism.

### 2. Primitive schema

Avoid defining primitive only negatively as “not uniformly synthesized.” Instead define:

```text
Derived(phi) iff there exists a transparent derivation term using the allowed generator set.
Primitive(phi) iff not Derived(phi), after normalization.
```

Then specify whether `Primitive` is decidable in the formal calculus or merely carried as a proof/tag.

### 3. Support and arity

Define support over layer identifiers:

```text
support(phi) := minimal finite set of layer IDs whose public schemas occur in phi's normalized type.
arity(phi) := |support(phi)|.
```

Prove minimality/invariance under presentation equivalence.

### 4. Exact obligation object

Define the exact object as a realized type, not a set:

```text
Real_k(X) := interpretation of ObSig_k(X) as a dependent telescope/type.
```

This allows contractibility statements to make sense.

### 5. Minimal-signature depth

Define it over primitive trace fields in normalized signatures:

```text
d_mu <= d iff every admissible declaration has a presentation-equivalent representative
whose primitive trace fields all have arity <= d.
```

### 6. Chronological window

Define separately from arity:

```text
Window(d) iff every primitive trace field at stage n+1 has support contained in
{L_n, ..., L_{n-d+1}}, and every remote comparison factors through those layers.
```

This should be the hypothesis used by the recurrence theorem.

### 7. Full coupling footprint

Define:

```text
Footprint_full(n,d) := disjoint union of S_bas(L_n), ..., S_bas(L_{n-d+1}).
```

A sparse extension uses a subset. A fully coupled extension uses all of it.

## Decision tree if the hard theorem fails

The most likely hard failure is the horn-extension contractibility theorem. The paper can still be made publishable if it pivots correctly.

### If contractibility is fully provable

Keep the exact obligation-depth theorem:

```text
Real_k(X) ~= Real_2(X), k >= 2.
```

Then the paper is a strong theorem paper, provided the artifact is public.

### If only canonical derived witnesses are provable

Revise the main result to:

```text
Higher structural trace fields are canonically derived and eliminated from mu-minimal
public signatures. Primitive support has a two-layer chronological window. Therefore the
minimal opaque cost recurrence is depth-two.
```

Drop or weaken:

```text
O^(k)(X) ~= O^(2)(X)
```

This version is still publishable as a theorem about normalized public-signature cost.

### If recent-history factorization is only formalized for a specific grammar

State the grammar-specific theorem. Do not present it as a theorem about all foundational core extensions.

### If the raw bridge is only partial

Say exactly which raw declaration constructors are covered. Restrict examples and theorem statements to those constructors.

## Final publication standard

A theorem-paper version should leave a skeptical reviewer with no need to infer the missing formal structure. The revised paper should make the following completely explicit:

- what calculus is being studied;
- which declarations are admissible;
- what “fully coupled” means;
- what exactly is counted;
- what is a signature-level statement versus a type-level statement;
- how cubical horn computation enters;
- whether horn extension spaces are actually contractible or merely canonically represented;
- why binary obligations are necessary;
- why remote history does not add primitive trace fields;
- why the recurrence follows;
- what has been machine-checked.

If those points are fixed, the paper can become a convincing and potentially publishable theorem paper. Its best contribution is not the slogan “Fibonacci growth,” but the precise separation of exact obligation depth, minimal public-signature depth, and chronological window size inside a sealed cubical extension-cost calculus.
